# Pair Review

I want you to engage in an analysis using another AI agent. You can use `gemini -p <prompt>`.

The workflow should be:

- Run your own analysis first
- Ask the agent to run the same analysis in parallel
- Compare both outputs twice to see if there are gaps or conflicts:
    1. Your own analysis of a vs. b
    2. Asking the agent to conduct it's own analysis of a vs. b
- Collect both reports and consider them yourself.
- Incorporate good ideas from the agent into your final report.
