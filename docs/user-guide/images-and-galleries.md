# Images and Galleries

Studiorum defaults to simple, macro‑based image placement. Output is emitted via small LaTeX helpers, never hard‑coded LaTeX in Python.

- Single images use shape‑named commands like `\StudiorumImageInline` and `\StudiorumImageFloat`.
- Galleries call `\StudiorumImageInlineNoCaption` inside `subfigure`s.
- Smart placement remains opt‑in and deprecated (`--placement-mode=smart`).

## Single Images

Commands:

- `\StudiorumImageInline[.8]{file}{caption}[label]` — inline, non‑floating.
- `\StudiorumImageFloat[.8]{file}{caption}[label]` — standard float `[htbp]`.
- `\StudiorumImageWide[.8]{file}{caption}[label]` — two‑column span in `twocolumn`.
- `\StudiorumImageFullpage[.95]{file}{caption}[label]` — dedicated page; keeps aspect.
- `\StudiorumImageFullpageBleed{file}{caption}[label]` — fills physical page (may distort).

Example:

```latex
% Auto-generated label comment is added by the partial
\StudiorumImageInline{images/dragon.png}{Ancient Red Dragon}[fig:ancient-red-dragon]
```

CLI integration (manual by default):

```
studiorum convert ... --placement-mode manual
```



## Galleries

Galleries are generated by the LaTeX engine through a Jinja2 template (`_gallery_render_block.tex.j2`) and call `\StudiorumImageInlineNoCaption` inside `subfigure` containers. Available layouts:

- `grid` — N×M grid with column count
- `sequential` — vertical sequence with spacing
- `comparison` — side‑by‑side (equal widths)
- `showcase` — featured main image with optional decorative header/borders and thumbnails

Select layout via CLI:

```
studiorum convert ... --gallery-layout grid    # grid|showcase|sequential|comparison
```

### Content entry (JSON/YAML‑like) example

```json
{
  "type": "gallery",
  "layout": "grid",
  "columns": 2,
  "caption": "Dragon Age Comparison",
  "images": [
    {"href": {"path": "images/dragon_ancient.png"}, "title": "Ancient"},
    {"href": {"path": "images/dragon_young.png"},   "title": "Young"}
  ]
}
```

### Showcase decorations

Showcase layout can add tasteful decorations (header line, featured border, thumbnail separator, stylized caption). These are guarded by engine configuration and rendered entirely in the template using TikZ/xcolor. The default color scheme is `dndred`.

Notes:
- Decorations are template‑side only; disabling decorations avoids emitting the word “decorative” (useful for tests/grepping).
- Even in showcase, each image inclusion uses the same simple command, so sizing/captions remain consistent.

## Tips

- Keep `placement_mode=manual` for predictable output and reproducible LaTeX.
- Use labels and `\ref{...}` for references; Studiorum auto‑generates labels from titles when possible.
