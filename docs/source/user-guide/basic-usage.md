## Command Line Interface

The `5e2pdf` command provides a simple interface for converting D&D 5e content to PDF:

```bash
# Basic usage
uv run 5e2pdf --help

# Convert specific content types
uv run 5e2pdf spells
uv run 5e2pdf monsters
uv run 5e2pdf items
```

## Configuration

Configuration options can be set via:
- Command line arguments
- Configuration files
- Environment variables

## Output Formats

- **PDF**: High-quality LaTeX-generated PDFs
- **LaTeX**: Raw LaTeX source files
- **HTML**: Web-friendly output (planned)
