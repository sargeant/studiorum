## Prerequisites

- Python 3.12+
- uv package manager
- LaTeX distribution (for PDF generation)

## Quick Install

```bash
# Clone the repository
git clone https://github.com/yourusername/5e2pdf.git
cd 5e2pdf

# Install with uv
uv sync
```

## Verify Installation

```bash
uv run 5e2pdf --help
```

For more detailed setup instructions, see our [quickstart guide](../quickstart.md).
